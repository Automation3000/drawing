# Drawing (Personal Diagram Tool)

## About

This is a custom, self-hosted diagramming and whiteboarding application. It has been specifically modified and hosted for **Personal Use** to create **Plant Drawings** (such as P&IDs, control loops, and instrumentation diagrams). 

This tool is based on the original open-source project (JGraph) and has been customized to streamline personal workflows. It is deployed here: [https://draw.Automation3000.com](https://draw.Automation3000.com)

## Purpose & Scope

**Strictly for Personal Use.**
The primary objective of this setup is to maintain a private, dedicated workspace. Custom stencils and pre-defined items (like valves, transmitters, and plant components) are incorporated so they can be easily accessed and directly used via drag-and-drop without searching repeatedly. 

This is not a commercial project or a public collaborative platform.
